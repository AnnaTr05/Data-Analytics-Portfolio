## Project Overview This project uses historical airline route data to develop a predictive model for airfare prices. Using a dataset containing 638 U.S. air routes, I explored relationships between airfare and route-related variables through correlation analysis, scatterplots, and multiple linear regression. The dataset was divided into training and validation sets to evaluate the model's predictive performance. I also considered which variables would be practically available when pricing a new airline route. ## Key Findings - Distance was the strongest individual numerical predictor of airfare, with a correlation of approximately 0.686. - The multiple linear regression model was evaluated using a validation dataset. - Validation performance: - Mean Absolute Error (MAE): $27.61 - Root Mean Squared Error (RMSE): $35.59 - Mean Absolute Percentage Error (MAPE): 21.15% - The project highlighted the importance of selecting predictors that are available when a new route is introduced. ## Tools & Techniques R, Multiple Linear Regression, Correlation Analysis, ggplot2, corrgram, Data Visualization, Train/Validation Split, MAE, RMSE, MAPE.
