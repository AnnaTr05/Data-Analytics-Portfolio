Project objective:

The goal of this project was to explore coffee consumption patterns using data analysis and interactive visualizations. The project focused on understanding how coffee consumption varies across different age groups and examining the distribution of coffee brewing methods.

1. Data Cleaning & Preparation
- Used R and dplyr to clean and prepare the dataset.
- Handled missing data.
- Organized and separated coffee brewing methods for analysis.

2. Exploratory Data Analysis (EDA)
I dived in into 2 questions throughout the project in order to tell a story to audience:
What are the distributions of different coffee brewing methods?
How does daily coffee consumption vary across different age groups?b

3. Data Visualization
Chart 1: Distribution of coffee brewing methods.
Chart 2: Daily coffee consumption by age group.

4. Interactive Dashboard
I used Shiny to develop an interactive dashboard that allows users to explore coffee consumption data.
- Created an interactive chart to visualize the distribution of different coffee brewing methods.
- Developed a second chart with an Age Range dropdown filter.
- Enabled dynamic chart updates based on the selected age group, allowing users to compare coffee consumption patterns across different age ranges.
