# Coffee Consumption Analysis

## Project Overview

This project explores coffee consumption patterns using survey data, focusing on popular coffee brewing methods and daily coffee consumption across different age groups. An interactive dashboard was developed using R Shiny and Flexdashboard to visualize and explore the survey results.

## Objective

Analyze coffee brewing preferences and examine how daily coffee consumption varies across different age groups through interactive data visualization.

## Tools

- R
- R Shiny
- Flexdashboard
- ggplot2
- Plotly
- dplyr
- Tidyverse

## Methods

- Data collection and preprocessing
- Exploratory Data Analysis (EDA)
- Data aggregation and grouping
- Interactive data visualization
- Age-based filtering
- Dashboard development using R Shiny

## Key Findings

- **Coffee Brewing Preferences:** The project examines the distribution of different coffee brewing methods, providing an overview of respondents' brewing preferences.

- **Age-Based Consumption Patterns:** Daily coffee consumption is analyzed across different age groups to explore variations in the number of cups consumed.

- **Interactive Data Exploration:** The dashboard allows users to select specific age groups and dynamically explore their coffee consumption patterns.

- **Data Visualization:** Interactive Plotly charts and ggplot2 visualizations make survey results easier to explore, compare, and interpret.

- **Practical Application:** The analysis demonstrates how interactive dashboards can transform survey data into accessible insights about consumer preferences and behaviors.
