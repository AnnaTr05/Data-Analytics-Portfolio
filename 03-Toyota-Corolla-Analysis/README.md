
# Toyota Corolla Price Prediction

## Project Overview
This project focuses on predicting used Toyota Corolla prices using vehicle characteristics and statistical modeling.

## Objective
Analyze the factors that influence the resale price of Toyota Corolla vehicles and develop a predictive model.

## Tools
- R
- Regression Tree
- Data Analysis
- Data Visualization

## Methods
- Data preprocessing
- Exploratory Data Analysis
- Regression modeling
- Model evaluation

## Key Findings
The project examines how vehicle characteristics contribute to used car prices.
