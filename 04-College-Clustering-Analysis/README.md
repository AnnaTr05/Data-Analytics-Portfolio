
# Clustering American Colleges and Universities

## Project Overview
This project applies unsupervised machine learning to group American colleges and universities based on their characteristics.

## Objective
Identify groups of institutions with similar characteristics using clustering techniques.

## Tools
- R
- Hierarchical Clustering
- Data Analysis
- Data Visualization

## Methods
- Data cleaning
- Data normalization
- Manhattan distance
- Complete linkage clustering
- Dendrogram analysis

## Key Findings
The clustering analysis identifies groups of colleges and universities with similar institutional characteristics.
