
# Bank Personal Loan Acceptance Prediction

## Project Overview
This project uses machine learning to predict whether bank customers are likely to accept a personal loan offer.

## Objective
Identify potential customers who are more likely to accept personal loan offers based on their demographic and financial information.

## Tools
- R
- k-Nearest Neighbors (k-NN)
- Data Analysis
- Data Visualization

## Methods
- Data preprocessing
- Exploratory Data Analysis
- k-NN classification
- Model evaluation

## Key Findings
The model explores customer characteristics and patterns associated with personal loan acceptance.
